# NEXUS AI

AI-powered marketing video generation platform for businesses.

## Features

- 🤖 AI Video Generation from text prompts
- ⚡ 5-minute video creation
- 📱 Multi-platform optimization (TikTok, Instagram, YouTube)
- 🎨 Brand consistency tools
- 📊 Performance analytics
- 💳 Stripe subscription integration

## Tech Stack

- Next.js 14 (App Router)
- React 18
- TypeScript
- Tailwind CSS
- Stripe (payments)

## Getting Started

```bash
npm install
npm run dev
```

## Environment Variables

```
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=
STRIPE_SECRET_KEY=
```

## Deployment

Deploy to Vercel:
```bash
vercel --prod
```
