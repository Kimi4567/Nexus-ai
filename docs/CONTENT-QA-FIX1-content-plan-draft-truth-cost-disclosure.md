# CONTENT-QA-FIX1 - Content Plan Draft Truth + Cost Disclosure

## Purpose

Fresh-account QA found that the Content Hub generation entry point did not show the content-plan cost before the user clicked, and generated draft posts could contain over-strong claims such as perfection, guaranteed delivery, or unsupported proof language.

This PR keeps the existing Content Hub flow, generation endpoint, credit deduction behavior, and draft-review lifecycle intact while adding a safer disclosure and deterministic draft-copy guard.

## What Changed

- Added visible Content Plan cost disclosure before generation and regeneration actions.
- Kept the same cost visible in locked/Add credits states.
- Added draft-only copy beside the generation CTA: generated content is for review only, and nothing is approved, scheduled, published, or activated.
- Added a deterministic `contentDraftTruthGuard` for generated draft post fields.
- Added guard coverage for:
  - perfection and absolute claims
  - minimal Arabic perfection, delivery, stock, and productivity claims
  - always-stocked claims
  - delivery claims without supported-zone bounds
  - unsupported testimonials, customer stories, reviews, awards, and case studies
  - paid budget, ROAS, CAC, and ad-launch assumptions
  - unsafe draft/active status wording
- Fixed the existing strategy proof guard phrase that could produce `Support more reliable team planning has access to great coffee`.
- Replaced the analytics insight banner copy `ready to activate` with `review before scheduling`.

## Compatibility Boundaries

Kept unchanged:

- Content plan generation route behavior and response shape.
- Credit deduction and refund behavior.
- Existing backend 402 protection.
- Existing SocialPost creation status: generated posts remain `DRAFT`.
- Approval, scheduling, publishing, Autopilot, billing, schema, and dashboard behavior.
- Existing saved campaign output and existing SocialPost rows.

## Why Analytics Insights Was Touched

The unsafe `ready to activate` banner is generated by `src/app/api/analytics/insights/route.ts`, not by the Campaign Room or Content Hub page. The change is copy-only and keeps the same insight type, icon, href, and campaign-count behavior.

## QA Notes

- Do not click generation during QA unless explicitly approved.
- Verify the Content Hub shows the cost before generation.
- Verify draft disclosure says nothing is approved, scheduled, published, or activated.
- Verify Campaign Room global insight copy no longer says `ready to activate`.
- Verify mobile width does not horizontally overflow.
