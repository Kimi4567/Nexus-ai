# STRATEGY-EXECUTION-PATH1

## Problem

The Strategy tab now contains a rich professional strategy document, but the operating path after reading it can still feel split across several surfaces:

- Strategy document sections.
- Content Hub post review.
- Creative requirements.
- Platform / paid readiness.

That can make a strong strategy feel like a report instead of an operating system.

## Decision

Add a read-only "Next operating path" strip near the top of the Strategy command center.

The strip routes the user in a clear order:

1. Review Content Hub posts or the paid planning brief.
2. Review Creative and media readiness.
3. Review platform / paid readiness in Connections.

The old secondary CTA "Review strategy sections" is reframed as "Read strategy document" so it no longer competes with the actual operating next action.

## Boundaries

- No generation.
- No approval.
- No scheduling.
- No publishing or manual publishing.
- No Autopilot activation.
- No paid launch or platform push.
- No API, schema, credits, data, SocialPost, Media, GeneratedVisual, Brand Brain, billing, dashboard, or engine behavior change.

The change is UI copy and routing only.
