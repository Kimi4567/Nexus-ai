# BRAND-RUNTIME-TRUTH2 — Analytics-gated Brand Brain memory copy

## Scope

This cleanup keeps the Brand Brain runtime surface aligned with the learning contract:

- Brand Brain guides strategy, content, and creative direction.
- Approval, selection, campaign, and review events are signals for review.
- Performance learning requires real analytics data.
- The Brand page must not imply automatic future learning from setup or workflow activity alone.

## Runtime copy cleanup

The old footer copy said:

- `تغذي Brand Brain الاستراتيجية والمحتوى والاتجاه الإبداعي والتعلّم المستقبلي.`

That Arabic line could imply future learning without analytics evidence.

The footer now says:

- `توجّه Brand Brain الاستراتيجية والمحتوى والاتجاه الإبداعي. إشارات المراجعة محفوظة، وتعلّم الأداء يحتاج تحليلات حقيقية.`
- `Your Brand Brain guides strategy, content, and creative direction. Review signals are saved; performance learning needs real analytics.`

Legacy assisted-preview labels were also tightened:

- `WINNING HOOKS` became `Reviewed hook signals`.
- `الـ HOOKS الناجحة` became `إشارات خطافات للمراجعة`.
- `Apply to Brand Brain` became `Add to draft for review`.
- `تطبيق على Brand Brain` became `أضف للمسودة للمراجعة`.

These preview actions populate the local draft for review. Persistence remains the separate explicit Save flow.

## Non-goals

This change does not:

- change Brand Brain scoring or readiness logic
- change learning events
- generate strategy, content, or images
- approve, schedule, publish, or manually publish
- spend credits
- mutate SocialPost, Media, GeneratedVisual, BrandProfile, campaign output, dashboard, billing, or analytics data
